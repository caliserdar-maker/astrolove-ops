# IS_0044 - Siparis yonlendirici: cerceveli ve dijital SKU eslemesi

Serdar karari 27 Eyl 2026: ilanlara Framed secenekleri eklenir (SKU `POD-<cift>-<ed>-<BOY>-F<BK|WH|NA>`), dijital SKU `...-DIGITAL`.
Kargo: STANDARD (Budget degil). Oncelik ABD lab.

## Yapilacak (`scripts/prodigi/order_router.py`, `scripts/etsy/pod_sku.py`)
1. SKU ayristirma: `-F<BK|WH|NA>` sonekini tani. Cerceveli kalem Prodigi SKU'su `data/pod/prodigi_cerceve_esleme.csv`'den gelir
   (`boy,cerceve,prodigi_sku,attr_color,attr_ek_json`); dosyada olmayan boy/renk -> kalem `manual` + warn `CERCEVE_ESLEME_YOK` (siparis gonderilmez).
   Ornek csv'ye yer tutucu 2 satir koy (gercek SKU'lar Prodigi taramasindan sonra gelecek).
2. Cerceveli kalem govdesi: `attributes` icinde cerceve rengi (csv `attr_color`), `sizing fillPrintArea`, ayni asset (baski dosyasi).
3. Kargo yontemi: parametre `--shipping-method` varsayilan `Standard` (eski Budget varsayilani degisir; teklif de Standard ile).
4. `-DIGITAL` kalemi: ASLA Prodigi'ye gitmez (mevcut dijital kontrol korunur; `scripts/prodigi/test_dijital.py` gecmeye devam etmeli).
5. Karma siparis (dijital + baski): yalniz fiziksel kalemler pakete girer.
6. Testler: `scripts/prodigi/test_cerceve_esleme.py`: cerceveli SKU ayristirma, esleme yok -> manual, Standard varsayilan,
   karma siparis, dijital 0 Prodigi cagrisi. Ag yok (Prodigi/Drive/Etsy sahte). Mevcut testler bozulmamali.
7. `docs/POD_ORDER_ROUTER.md`'ye 10 satiri gecmeyen "Cerceveli + dijital (27 Eyl)" bolumu.

Musteri verisi repoya/loga yazilmaz. Prodigi'ye gercek siparis yok.
