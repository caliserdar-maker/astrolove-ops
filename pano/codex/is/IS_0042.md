# IS_0042 - Ilan yapisi v2 yazici (Dijital + Baski + Cerceveli), 78 POD ilani

Serdar karari 27 Eyl 2026: magazada 78 ilan kalir. Her ilanda: Digital File + Print (kagit) + Framed (cerceveli).
Etsy en fazla 2 varyasyon verir. Yapi: Varyasyon 1 = Primary color (mevcut 5 renk, renk->gorsel eslesmesi KORUNUR),
Varyasyon 2 = "Size" degerleri formatla birlesik etiket: "Digital File (5 colors)", "8x10 Print", "8x10 Black Frame" ...
Secenek listesi ve fiyatlar koda gomulmez: `data/pod/yapi_v2.csv` dosyasindan okunur.

## Yapilacak
1. `scripts/pod/ilan_yapi_v2.py` (mevcut `scripts/pod/dijital_secenek_tek.py`, `dijital_secenek_plan.py`, `pod_pilot_15.py`,
   `scripts/etsy/etsy_common.py`, `scripts/etsy/pod_sku.py` kaliplarini kullan; tekrar yazma).
   - Girdi `data/pod/yapi_v2.csv`: `sira,etiket,tur(digital|print|framed),boy,cerceve(BK|WH|NA|),fiyat,sku_ek,aktif(1|0)`.
     Ornek 6 satirlik csv'yi de ekle (gercek fiyatlar sonra gelecek).
   - Modlar: `kuru <ilan|hepsi>` (Etsy'ye yazmaz; plan + diff CSV), `yaz <ilan|hepsi> --confirm YAPI_V2`, `--yalniz id,id`, `--kota-alt N` (varsayilan 400).
   - Plan: 5 renk x csv satirlari. SKU: baski mevcut sema (POD-<cift>-<ed>-<BOY>), cerceveli `...-<BOY>-F<BK|WH|NA>`, dijital `...-DIGITAL`.
     Mevcut urunlerde olan (renk,boy) icin SKU/adet/is_enabled korunur, fiyat csv'den gelir. `readiness_state_id` ve
     `price_on_property/quantity_on_property/sku_on_property` mevcut envanterden kopyalanir.
   - Ilan `active` degilse DOKUNMA (updateListing taslagi yayina alir). Kisisellestirme alanlari degismemeli (geri okuma).
   - Sira: ONCE yedek (out/Y2_<id>_ONCE.json) -> inventory PUT -> tam geri okuma (her urun sku/fiyat/adet/enabled) ->
     variation-images geri okuma, bozulduysa ayni degerlerle POST -> aciklama PATCH -> geri okuma. Ilk hatada DUR.
   - Aciklama: `data/pod/aciklama_v2_boy_blok.txt` icerigi, aciklamadaki "16 SIZES" ile baslayan bolumun YERINE yazilir
     (bolum = o satirdan bir sonraki "✦" ile baslayan baslik satirina kadar). `data/pod/aciklama_v2_dijital_blok.txt`
     yoksa eklenir, varsa dokunulmaz. Karsilastirmada iki taraf `html.unescape` + `\r\n`->`\n` + strip.
   - Idempotent: ikinci kosu ZATEN (exit 4). Cikis: 0 PASS, 3 ATLANDI, 4 ZATEN, 1 FAIL.
   - ETA sayaci (islenen/toplam, gecen, kalan, yuzde). Sirlar loga yazilmaz (`mask`). Musteri verisi yok.
2. `.github/workflows/ilan-yapi-v2.yml` (workflow_dispatch; inputs mod, ilan, yalniz, kota_alt, confirm; `concurrency: etsy-token`;
   token Drive `ASTROLOVE/TEMP/ETSY_TOKEN.json`, yenilenirse geri yazilir; out/ dosyalari Drive `TEMP/YAPI_V2/`'ye). `satis-kaynak.yml` kalibi.
3. `scripts/pod/test_ilan_yapi_v2.py`: sahte envanter (5 renk x 17 boy) ile plan/diff, SKU, korunan alanlar, aciklama bolum degisimi,
   html.unescape karsilastirma, idempotens. Ag yok. `python -m pytest -q` gecmeli.
