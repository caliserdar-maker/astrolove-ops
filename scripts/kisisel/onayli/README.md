# Kisisellestirme kilitleri

- Guncel Blue kilitleri oran bazlidir: `ISIM_SATIRI_<oran>.png` ve
  `TAGLINE_<oran>.png`.
- Guncel edisyon kilitleri alt klasorlerdedir ve ayni oran-bazli adlandirmayi
  kullanir.
- `TAGLINE_ALTIN.png` yalniz `pilot8.py` adli legacy olcum aracinin tarihsel
  girdisidir. `pilot16.py` ve `edisyon_uret.py` uretim akislarinda kullanilmaz.
- Kilit dosyalari Serdar'in acik onayi olmadan yeniden yazilmaz veya silinmez.
