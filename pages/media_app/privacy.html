Privacy Policy

AstroLoveArt Drive Automation. Effective date: October 22, 2026.

Who uses this app

AstroLoveArt Drive Automation is an internal tool of the AstroLoveArt shop. It has a single user: the shop owner. It is not available to the public.

What data the app accesses

With the shop owner's permission, the app accesses only the shop owner's own Google Drive files, documents and spreadsheets. It uses this access to copy, organize and update AstroLoveArt design and production files.

What the app does not do

  • It does not collect data from any other person or Google account.
  • It does not sell, share or transfer Google user data to anyone.
  • It does not use Google user data for advertising.
  • It does not use Google user data to train AI or machine learning models.

Storage and security

Files stay in the shop owner's Google Drive. The access credential is stored as an encrypted secret and is used only by the shop's own automated jobs.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The shop owner can remove the app's access at any time at myaccount.google.com/permissions.
